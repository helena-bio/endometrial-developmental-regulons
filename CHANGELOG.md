# Changelog

This changelog records repository-level changes to the public computational
and reproducibility record.

Scientific corrections must state whether they alter numerical values,
categories, verdicts, figures, or manuscript interpretation. Documentation
changes that do not alter scientific outputs are identified explicitly.

## Unreleased

### Documentation

- Expanded the repository README to describe the full five-package study
  structure rather than only the three sensitivity packages.
- Added the study question, cohort design, molecular-subtype contrasts,
  evidence taxonomy, main evidence map, repository navigation, source-data
  boundary, interpretation limits, citation status, and maintainer contact.
- Expanded the contributing guide with contribution categories, frozen-record
  protections, data and privacy requirements, validation expectations,
  authorship boundaries, and pull-request requirements.
- Expanded the code of conduct with scientific-integrity expectations,
  acceptable disagreement, privacy rules, reporting channels, scope, and
  enforcement principles.
- Expanded the reproducibility guide to distinguish release verification from
  complete analysis re-execution and to document package boundaries, source
  acquisition, deterministic comparison, independent checks, and scientific
  state hierarchy.

### Scientific impact

- No frozen protocol, source mapping, executable analysis, numerical result,
  figure, category, verdict, or validation record was changed.
- Documentation wording remains within the manuscript and supplementary
  claim boundaries.

### Release metadata

- Updated the public file manifest and SHA-256 records for documentation files
  changed in this documentation pass.
